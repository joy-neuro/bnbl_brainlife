## Running the App

### On brainlife.io

Open the App at [doi.org/10.25663/brainlife.app.460](https://doi.org/10.25663/brainlife.app.460), choose the input datasets from your project and press **Execute**.

### Locally

You need [Singularity/Apptainer](https://apptainer.org/) (the App runs in `filsilva/cxnetwork:0.2.0`), [`jq`](https://jqlang.github.io/jq/).

1. Clone this repository.
2. Create `config.json` with the paths to your inputs and the parameters:

   ```json
   {}
   ```

3. Run `./main`.
